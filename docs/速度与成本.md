# JEV 速度与成本：统计口径

数据：[`data/physician-tasks-100/jev-timeline.json`](../data/physician-tasks-100/jev-timeline.json)。价格于 **2026-09-28** 核对：[Vercel AI Gateway 的 JEV 输入价格为 $0.04 / 百万 tokens](https://vercel.com/ai-gateway/models/jev)。

## 速度

251 条 QA，每条 14 维，共 3,514 项判断。其中一条长输入采用 4 个分组请求，成功请求合计 254 次；该条耗时与用量按分组求和。

| 口径 | 中位数 | 均值 | P95 |
| --- | ---: | ---: | ---: |
| JEV 上游耗时 / QA（providerDurationMs） | 298 ms | 312 ms | 415 ms |
| 成功调用端到端耗时 / QA（durationMs） | 683 ms | 861 ms | 1,650 ms |

P95 采用排序后 `floor((n−1)×0.95)` 位置值。上游耗时由已归档的提供商计时字段统计；成功调用端到端计时包含网络及网关开销。两者均不代表包含 DeepSeek 复核、限流排队、失败重试及调度间隔的整条流水线耗时，也不是生产 SLA。

## 成本

- QA 数：251。
- 成功请求输入 tokens 合计：4,826,485。
- 每 QA 平均输入：19,229.02 tokens，包含规则、问答、历史和工具证据；长输入分组的重复计费输入已包含。
- 本批 JEV 估算费用：`4,826,485 ÷ 1,000,000 × 0.04 = $0.1930594`。
- 同等输入规模的 10,000 QA：`$0.1930594 ÷ 251 × 10,000 = $7.69161`，约 **$7.69**。

14 维已经包含在实际 token 用量中，不再乘 14。价格按输入 token 计，实际开销随上下文、规则长度、路由和重试变化。本批网关 `cost` 字段为 0，上述为公开单价估算，不是结算账单。

全流程预算应分别计入 **JEV 筛查 + DeepSeek 逐条复核 + 聚类 + 重试及运行资源**。本批 DeepSeek 复核覆盖 226 / 251 条 QA（约 90%），属于广覆盖探索评测；不能据此宣称已通过少量复核实现整个流程的低成本。生产复核比例需要结合漏报、误报及风险等级校准。

## 准确性与业务价值

本批得到 113 项有证据支持的模型复核发现，另有 1 项证据待补，归并为 22 个回答缺陷簇。未建立专家标注金标准，因此不报告准确率、精确率或召回率，也不将模型概率当作实测准确率。下一步使用人工标注集验证筛查质量，并保留未命中抽查与高风险问题的人工处理。
